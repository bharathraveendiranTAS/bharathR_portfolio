How to Host This Portfolio on GitHub Pages

Because this application uses semantic HTML5, Tailwind CSS via CDN, and vanilla JavaScript, it requires zero build steps or package installations. It runs instantly on any static web host.

Step 1: Create a GitHub Repository 01

Go to github.com/new and create a repository. For a personal user site, name it:

<your-username>.github.io
Step 2: Commit & Push index.html 02

Run these commands in your project folder: 

git init
git add index.html
git commit -m "Initial commit: developer portfolio"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
Step 3: Enable GitHub Pages in Settings 03
  1. Open your repository on GitHub.
  2. Navigate to Settings > Pages (in the left sidebar).
  3. Under Build and deployment > Source, select Deploy from a branch.
  4. Select main branch and folder / (root), then click Save.

✨ Within 60 seconds, your site will be live at: https://<your-username>.github.io/
